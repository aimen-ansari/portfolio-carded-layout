# Aimen's Portfolio

Create a premium, minimal, conversion-focused personal portfolio for Aimen Ansari — Full-Stack Developer.

The portfolio will be used for cold-email outreach, LinkedIn, freelancing, and client acquisition, so the website must immediately show potential clients what I can build, proof through real projects, and an easy way to contact me.

The overall feeling should be:

Premium · Technical · Minimal · Calm · Developer-focused · Business-oriented

Do not create a typical colorful developer portfolio. Avoid purple/blue gradients, neon effects, excessive animations, floating coding icons, 3D objects, glowing cards, huge hero illustrations, or crowded layouts.

Visual Theme

Create both dark and light themes.

Dark / Cocoa Mode

Background: #18110E

Surfaces: #241915, #33221C

Main text: #F3E9DA

Nude accent: #D0B39F

Muted brown: #987462

Light / Cream Mode

Background: #F4EBDD

Surfaces: #EDE0D0

Main text: #2B1D18

Secondary text: #765A4B

Nude accent: #C8A995

Avoid pure black and pure white.

Use a modern font such as Geist, Manrope, or Inter, with Geist Mono / JetBrains Mono only for small developer-style labels.

Floating Navbar

Create a floating glass navbar fixed near the top.

Desktop layout:

Skills · Projects · Contact · [ AIMEN / dev_ ] · Home · About · Theme

The AIMEN identity should sit in the center inside a slightly raised circular/rounded glass element and act as the site's logo. Clicking it returns to Home.

Use subtle glass blur and thin borders. No heavy shadows.

Add a minimal light/dark theme control such as ◐.

On mobile use:

[ AIMEN / dev_ ] ☰

with a clean menu drawer.
